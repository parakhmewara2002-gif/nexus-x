PROJECT: NEXUS FILES — NEXT-GENERATION ANDROID FILE MANAGER

Act as a world-class Apple-level UI/UX designer, motion designer, and Android product designer.

Design an ultra-premium, futuristic Android file manager with the visual quality of iOS 26, Apple's Liquid Glass aesthetic, and the functionality of a professional desktop file explorer.

The app should feel like a premium operating system experience, not a typical Android file manager.

Create a unique visual identity combining:

- iOS 26 Liquid Glass visual language.

- Realistic background blur and glass refraction.
- Soft ambient lighting and subtle reflections.
- Layered depth and floating UI elements.
- Ultra-smooth spring-based transitions.
- Premium minimalism.
- Beautiful typography and spacing.

Avoid generic Material Design layouts and ordinary file-manager templates.

11. DESIGN QUALITY RULES

- Use a consistent 8-point spacing system.
- Use carefully balanced typography.
- Maintain excellent visual hierarchy.
- Create realistic file and folder thumbnails.
- Use high-quality custom icons.
- Avoid clutter.
- Avoid excessive gradients.
- Avoid excessive glass blur.
- Ensure text remains readable over glass surfaces.
- Make every screen feel like part of the same premium application.
- Design for modern Android smartphones, including 360–430 dp screen widths.
- Respect Android status bar, navigation gestures and safe areas.
